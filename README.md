An entry for the make.fun competition
[Make the AI Judge Laugh: Office Jokes](https://make.fun/c/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a).

## What it does

`main.py` writes one single-line joke about office life — under 200
characters, with a surprise turn at the end — to `/output/entry.txt`,
where the competition's judge reads it:

> My boss says we're one big family here, so I asked HR when the family
> reunion starts covering my therapy bills.

## Run it

```sh
python3 main.py
```

In the competition sandbox this writes `/output/entry.txt`; on a local
machine it writes `output/entry.txt` next to the program instead.
